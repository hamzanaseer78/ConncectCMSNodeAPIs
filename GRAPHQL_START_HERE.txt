🚀 TRY IT NOW (5 Minutes)

1. Start server:
   npm run dev

2. Get JWT token:
   curl -X POST http://localhost:3000/api/auth/signin \
     -H "Content-Type: application/json" \
     -d '{"email":"user@example.com","password":"password"}'

3. Open playground:
   http://localhost:3000/graphql/playground

4. Paste token in "Bearer Token" field

5. In left panel, type: query {
   Press Ctrl+Space to see suggestions!

6. Select "dashboardSummary"

7. Press Ctrl+Space again for field suggestions

8. Select fields and run query

✅ Done! You're now using full schema introspection!
