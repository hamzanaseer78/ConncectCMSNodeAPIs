🚀 QUICK START FOR USERS

1️⃣ Start Server
   npm run dev

2️⃣ Get JWT Token
   curl -X POST http://localhost:3000/api/auth/signin \
     -H "Content-Type: application/json" \
     -d '{"email":"user@example.com","password":"password"}'

3️⃣ Open Playground
   http://localhost:3000/graphql/playground

4️⃣ Paste Token
   • Click Bearer Token field
   • Paste JWT token
   • ✓ Authenticated

5️⃣ Explore Schema
   • Right panel: Schema Explorer
   • Left panel: Query editor
   • Ctrl+Space: Auto-complete
   • Hover: Documentation

🎯 AVAILABLE QUERIES

1. dashboardSummary
   • Get dashboard metrics (users, customers, products, etc.)
   • No parameters
   • Auth: Required ✓

2. resourceReport(resource)
   • Get count for specific resource
   • Parameter: resource (string)
   • Supported: customers, products, users, areas, branches, etc.
   • Auth: Required ✓

3. reports
   • Get all resource reports at once
   • No parameters
   • Returns array of all resources
   • Auth: Required ✓

📞 TROUBLESHOOTING

Problem: "Missing bearer token"
Fix: Paste JWT in Bearer Token field

Problem: "Token has expired"
Fix: Get new token from /api/auth/signin

Problem: No schema showing
Fix: Refresh browser (F5)

Problem: Autocomplete not working
Fix: Press Ctrl+Space explicitly

Problem: Error running query
Check: Is token valid?
Check: Are parameters correct?
Check: See bottom panel for error details
